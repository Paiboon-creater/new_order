คู่มือการใช้งานระบบ: สร้างใบสั่งผลิต (JAGUAR PRODUCTION)

หน้านี้ออกแบบมาเพื่อใช้สำหรับบันทึก ดูรายงาน แก้ไข และลบ "ใบสั่งผลิต" ภายในระบบฐานข้อมูลของบริษัท โดยแบ่งการใช้งานออกเป็น 4 ส่วนหลักดังนี้ครับ

1. การสร้างใบสั่งผลิตใหม่ (Add New Order)

ใช้สำหรับนำเข้าข้อมูลงานผลิตใหม่เข้าสู่ระบบ

  • เลขที่ใบสั่งผลิต: พิมพ์เลขที่ใบสั่งงานของทางโรงงาน (จำเป็นต้องกรอก)
  • เลขที่ใบสั่งซื้อ (PO): พิมพ์เลขที่ PO จากลูกค้า (จำเป็นต้องกรอก)
  • รหัสชิ้นงาน: คลิกเพื่อเลือกรหัสชิ้นงานจากรายชื่อ (ระบบจะดึงข้อมูลจากฐานข้อมูลมาให้เลือกอัตโนมัติ กรณีที่ไม่มีในรายการให้เลือกแสดงว่า สินค้าตัวนี้ไม่เคยมีการผลิตมาก่อน จำเป็นจะต้อง ไปเพิ่มรหัสสินค้า,เพิ่มขั้นตอนทำงาน,และยอดผลิตมาตรฐานเสียก่อน)
  • จำนวนที่ต้องการผลิต: ใส่ตัวเลขจำนวนชิ้นงาน
  • วันที่เริ่มต้น / วันที่กำหนดเสร็จ: คลิกที่ไอคอนปฏิทินเพื่อเลือกวันที่ (ระบบจะตั้งค่าเริ่มต้นเป็นวันที่ปัจจุบันให้โดยอัตโนมัติ)
  • การบันทึก: เมื่อตรวจสอบข้อมูลครบถ้วน ให้กดปุ่ม [ บันทึกข้อมูลใบสั่ง ] ด้านล่างสุด ระบบจะแจ้งเตือนเมื่อบันทึกสำเร็จและข้อมูลจะไปปรากฏในตารางด้านล่าง
2. การดูรายงานและตัวกรอง (Report & Filtering)

ตารางด้านล่างสุดจะแสดงประวัติใบสั่งผลิตทั้งหมดที่เคยบันทึกไว้

  • รีเฟรชข้อมูล: หากต้องการอัปเดตข้อมูลล่าสุดจากฐานข้อมูล ให้กดปุ่ม [ รีเฟรชข้อมูล ] ที่มุมขวาบนของตาราง
  • ตัวกรองเลขที่ใบสั่งซื้อ (PO): หากต้องการค้นหางานเฉพาะเจาะจง ให้คลิกที่ช่องตัวกรอง แล้วเลือกเลขที่ PO ที่ต้องการ ระบบจะกรองและแสดงผลเฉพาะใบสั่งผลิตที่ตรงกับ PO นั้นให้ทันที
3. การแก้ไขข้อมูล (Edit Data)

หากต้องการแก้ไขข้อมูลใบสั่งผลิตที่บันทึกไปแล้ว ให้ทำตามขั้นตอนดังนี้:

  • เลื่อนไปที่ตารางรายงานด้านล่างสุด ค้นหารายการที่ต้องการแก้ไข แล้วกดปุ่ม [ แก้ไข ] (สีเหลือง)
  • ระบบจะล็อกการเข้าถึงด้วยความปลอดภัย ให้คุณกรอกรหัสผ่าน (PIN) คือ 112233
  • เมื่อรหัสถูกต้อง ข้อมูลเดิมจะถูกดึงกลับขึ้นไปแสดงบนฟอร์มด้านบน
  • ทำการแก้ไขข้อมูลที่ต้องการ
  • กดปุ่ม [ บันทึกการแก้ไข ] เพื่อยืนยัน (หากเปลี่ยนใจ ไม่ต้องการแก้ไขแล้ว ให้กดปุ่ม [ ยกเลิกการแก้ไข ] สีแดง)
4. การลบข้อมูล (Delete Data)
  • ในตารางรายงาน ให้กดปุ่ม [ ลบ ] (สีแดง) ที่ท้ายรายการที่ต้องการลบ
  • ระบบจะขอให้กรอกรหัสผ่าน เพื่อป้องกันการลบข้อมูลโดยไม่ตั้งใจ
  • เมื่อกรอกรหัสถูกต้อง ข้อมูลนั้นจะถูกลบออกจากฐานข้อมูลอย่างถาวร
